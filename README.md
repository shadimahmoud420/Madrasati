# مدرستي – مدرسة رقمية متكاملة لطلاب غزة

تطبيق Flutter واحد يعمل على **Android و iOS** لطلاب الصف الأول حتى الثاني عشر وفق المنهج الفلسطيني، مبني على مبدأ **Offline First**: كل شيء يعمل بدون إنترنت بعد التحميل، والمزامنة تتم تلقائيًا عند عودة الاتصال.

> هذا مشروع مستقل تمامًا عن تطبيقاتنا الأخرى: مستودع خاص، ومعرّف تطبيق خاص (`com.madrasatigaza.madrasati`)، و Codemagic خاص.

## ما الذي يعمل الآن (المرحلة الأولى)

| الميزة | التفاصيل |
|---|---|
| عدة طلاب على جهاز واحد | شاشة «من يدرس الآن؟»: كل طالب يختار بطاقته باسمه وصورته، بدون كلمة مرور. لكل طالب صفه وتقدّمه ونتائجه وعلاماته المرجعية، ولا يرى بيانات غيره. «تبديل الطالب» من الرئيسية أو الإعدادات |
| اختيار الصف | المرحلة ← الصف (مع العلمي/الأدبي للثانوية) ← الفصل الدراسي. يمكن تغييره من الإعدادات |
| الكتب الرسمية PDF | إما **داخل التطبيق** (`assets/books/`، بلا أي تحميل) أو **على الخادم** (`tool/upload_books.py`) وتُحمَّل تلقائيًا لكتب صف الطالب عند توفر الإنترنت. تظهر في صفحة كل مادة حسب الفصل، وتُقرأ بدون إنترنت بجودتها الأصلية مع البحث داخل الكتاب والانتقال لصفحة والعلامات. ويمكن إضافة كتاب PDF من الجهاز |
| الصفحة الرئيسية | متابعة الدراسة، خطة اليوم، نسبة التقدم، المواد، الامتحانات، التوصيات، النقاط والمستوى وسلسلة الأيام، زرّا «اختبرني» و«المعلم الذكي» |
| الدروس | وحدات ← دروس، وفي كل درس: الأهداف، الشرح، الأمثلة، الصور، الفيديو (عند توفره)، أهم النقاط، الملخص، أسئلة تدريبية مع تصحيح فوري، اختبار سريع |
| الكتاب | تصفح الصفحات، البحث داخل الكتاب، الانتقال إلى صفحة، علامات مرجعية، ربط كل صفحة بدرسها |
| بنك الأسئلة | 7 أنواع: اختيار من متعدد، صح وخطأ، أكمل، صِل، إجابة قصيرة، مقالي، مسائل رقمية + أسئلة بالصور. 4 مستويات: سهل، متوسط، صعب، متقدم |
| اختبرني | يختار أسئلة تناسب مستوى الطالب في كل درس (أسهل عند الضعف وأصعب مع التحسن). النتيجة: الدرجة، النسبة، الصحيح والأخطاء مع الشرح، الوقت، الدروس التي تحتاج مراجعة |
| الامتحانات التجريبية | نماذج جاهزة بمؤقت، أو امتحان مخصص (المادة، عدد الأسئلة، الصعوبة، المدة)، تصحيح تلقائي، والمقالي يُعرض مع الإجابة النموذجية |
| التعليم الشخصي | نقاط القوة والضعف لكل درس، ومسار مقترح: الشرح ← الملخص ← التدريب ← إعادة الاختبار |
| لوحة التقدم | إنجاز المنهج، النجاح في كل مادة، عدد الدروس والاختبارات، دقائق التدريب، المقارنة بالأسبوع السابق |
| التحفيز | نقاط، مستويات، 8 شارات، تحدي يومي، سلسلة أيام متتالية |
| البحث الذكي | في المواد والوحدات والدروس وصفحات الكتب والأسئلة والامتحانات، يتجاهل التشكيل وأشكال الهمزة و«ال» |
| المعلم الذكي | يجد الدروس المتعلقة بالسؤال من المحتوى المحفوظ على الجهاز ويرسلها مع السؤال (RAG)، فيجيب من المنهج وبمستوى الصف. يوضح أنه يحتاج إلى إنترنت، ويقترح الدروس المناسبة عند انقطاعه |
| الإشعارات | تذكير يومي محلي بنصوص تعليمية متغيرة (درس يحتاج مراجعة، الدرس التالي، تحسّن المستوى…) |
| الخصوصية | لا بريد ولا هاتف ولا صور. الاسم اختياري ويبقى على الجهاز. حذف السجل من الإعدادات |
| التصميم | عربي RTL بالكامل، ألوان لكل مرحلة (برتقالي للصغار وخط أكبر، أخضر مزرق، نيلي للثانوية)، وضع داكن |

**المحتوى المرفق:** فهرس كامل للصفوف 1–12 وموادها، ومحتوى تجريبي كامل (11 درسًا، 6 كتب، 73 سؤالًا، 4 امتحانات) للصف **الرابع** والصف **التاسع**. هذا محتوى للتجربة كتبناه بأنفسنا وليس نص الوزارة الرسمي، ويُستبدل بالمحتوى المعتمد من الخادم دون تحديث التطبيق. باقي الصفوف تظهر برسالة «قيد الإعداد».

## البنية
```
lib/
  core/        الثيم، التوجيه، المزوّدات (Riverpod)، أدوات العربية والبحث
  data/        النماذج (صف ← مادة ← وحدة ← درس ← أسئلة)، SQLite المحلية، الاتصال بالخادم
  features/    home, subjects, lessons, books, quiz, progress, search, tutor, settings, onboarding
assets/content/ catalog.json + packs/<grade>.json + images   ← تولّدها tool/build_content.py
supabase/      المخطط والصلاحيات (RLS) + دالتا content و ai-tutor
test/          47 اختبارًا: التصحيح، الاختيار التكيفي، المحتوى، قاعدة البيانات، المزامنة، وسيناريوهات الواجهة
```

- **العمل بدون إنترنت:** محتوى كل صف «حزمة» JSON محفوظة في SQLite مع رقم إصدار. التطبيق يحمّل الحزم المرفقة عند أول تشغيل، ويسحب الإصدار الأحدث من الخادم عند الاتصال، ولا يستبدل حزمة صالحة بتنزيل تالف.
- **المزامنة التلقائية:** كل نتيجة تُحفظ محليًا أولًا مع معرّف فريد، وتُرسل عند عودة الاتصال (عند فتح التطبيق، وبعد كل اختبار، وعند السحب للتحديث) دون تكرار.
- **قابل للتوسع:** إضافة صف أو مادة أو درس = صفوف في قاعدة البيانات ثم `publish_pack`. الجداول جاهزة لحسابات ولي الأمر والمعلم (المرحلة الثانية).

## خارطة الطريق
- **المرحلة الثانية:** حسابات ولي الأمر والمعلم (الجداول والصلاحيات جاهزة)، لوحة إدارة ويب، عرض كتب PDF الرسمية.
- **المرحلة الثالثة:** تحليلات متقدمة، تصوير المسألة وحلها خطوة بخطوة.
